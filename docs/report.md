## Проверка модели

TODO: какие таблицы, ключи, DEFAULT и CHECK проверил в pgAdmin?

readers - хранит информацию о читателях. id первичный ключ, имеет btree индекс. email имеет btree индекс, плюс обязан быть уникальным.

authors - таблица имеет две колонки id, name. id в ней является первичным ключом, а также в следствии имеет индекс btree. 

categories - хранит информацию о категориях книг. id первичный ключ, btree индекс. title unique constraint

loans - хранит информацию о займах читателей. id первичный ключ, btree индекс. reader_id внешний ключ, который ссылается на читателей, book_id внешний ключ который ссылается на книгу. Дата окончания займа не должна быть раньше даты самого займа. Дата возврата может  существовать только если займ существует. Также если returned=FALSE, returned_date должен быть NULL. Если returned=TRUE, returned_date обязателен. 

books - хранит информацию о книгах. id первичный ключ. Проверки: копии  и цена не могут быть меньше 0. Год выпуска должен быть диапазоне 1900 и 2026 включительно. У книг есть внешний ключ который ссылается на категории. 

book_authors - таблица которая соединяет авторов и книги. имеет два внешних ключа book_id, author_id. А также составной индекс из book_id, author_id
